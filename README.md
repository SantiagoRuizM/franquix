# Franquix — Franchiser as a Service

Reactive REST API to manage franchise networks: **franchises → branches → products with stock**.

> Work in progress. See [`docs/MVP_SPEC.md`](docs/MVP_SPEC.md) for the full scope.

## Quick start

```bash
./gradlew build
```

Requires JDK 17+ to run Gradle; a JDK 21 toolchain is downloaded automatically when missing.
